# 성분 분류 매칭

2026-10-19에 wip-resource-deployer/resources의 cannabis 4행, narcotics 153행, psychotropics 337행, prohibited_list 24행과 pill_data 23,894행을 확인했다. 원본 리소스는 수정하지 않는다.

## 조회와 판정

- chemicalNameKr/chemicalNameEn은 이름·이명에 대한 리터럴 부분 검색이다. %와 _를 와일드카드로 처리하지 않는다.
- containedInKr/containedInEn은 복합제의 **성분별** 정식명·이명·CAS 일치 판정이다. 두 조건을 함께 보내면 AND로 적용한다.
- 위치번호의 쉼표, 괄호와 입체이성질체를 보존하고 공백·하이픈·전각문자·그리스문자, 허용한 염·수화물 표기만 정규화한다. 메틸/아세틸 등의 구조명은 임의 제거하지 않는다.
- 국문 표기 변형은 단일 성분 알약의 한영 이름이 일대일로 대응할 때만 보완한다. 복합제의 한영 성분 순서는 같다고 가정하지 않는다. 생성 결과는 ingredient_name_pairs.json이다.
- prohibited_list의 contents는 문서 원문 검색이다. 금지 성분 판정에는 containedInKr/containedInEn 또는 상세 분류 서비스를 사용한다.
- 공백·제로폭 문자만 있는 검색 조건은 빈 결과를 반환한다. 미지원 검색 조건은 예외를 발생시켜 조건 없는 조회로 바뀌지 않게 한다. 빈 contents 행은 원문 목록에서도 제외한다.

## 도핑 문서

현재 데이터는 영문 원문과 한글 번역이 페이지별 한 행에 함께 있다. 목차·서문·방법·모니터링 프로그램·변경 주해를 제외한 15개 본문을 판정에 사용한다. S3/S5/S6/S8/S9의 예외 구역을 금지 성분 본문과 구분한다. Cannabidiol, caffeine, bupropion, 모니터링 대상 codeine 등은 단지 문서에 등장한다는 이유로 금지 판정하지 않는다.

isProhibited는 금지 목록에 일치하는 성분이 있어 주의가 필요하다는 의미다. 용량·소변 농도·투여 경로·성별·연령·경기기간·종목·TUE를 모두 판정하는 복용 허용 여부 계산기가 아니다. 화면에 분류별 적용 조건을 함께 제공한다. 예시 목록에 없는 모든 유사체나 포괄적 약물군을 분자 구조로 추론하지 않는다. 문서 구성이 변경되면 파서와 테스트 스냅샷도 함께 검토해야 한다.

## 검증 및 갱신

실제 518행의 필요한 필드를 테스트 fixture에 보관한다. 분류 494행의 정식명과 파싱한 이명으로 원래 행을 찾는지, 실제 문서의 예외·임계치·표기 변형·빈 검색·복합제 경계를 검사한다. 이는 리소스 일치 검사이며 전체 의약품의 법적 분류 정확도 비율을 뜻하지 않는다.

분류 카탈로그·이명 인덱스·상세 분류 결과 캐시를 재사용한다. 관련 DB 테이블 삽입/삭제 후 카탈로그를 무효화하므로 다음 판정은 새 데이터를 사용한다.
